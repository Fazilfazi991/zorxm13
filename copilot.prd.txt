STEP 4 — TAB 1: SEO RULES CHECKER
═══════════════════════════════════════════════════════════

FILE: tools/SEORulesChecker.tsx
HOOK: hooks/useRulesChecker.ts
DATA: data/rules.json

INPUT PANEL:
Two input modes toggled by radio buttons:
  Mode A — "Paste Content": 
    - Focus Keyword (text input, required)
    - Post Title (text input)
    - Meta Description (textarea, 160 char counter)
    - Content (large textarea, word count live display)
    - URL Slug (text input)
    - Content Type dropdown: Blog Post / Product Page / 
      Landing Page / WooCommerce Product
    - [Analyze Content] button (indigo, full width)

  Mode B — "Quick Check" (basic fields only):
    - Focus Keyword
    - Title
    - Word count (number input)
    - [Quick Analyze] button

ANALYSIS LOGIC (useRulesChecker.ts):
Load rules.json. For each rule, evaluate its condition 
against the user's inputs using this mapping:

  title_length          = postTitle.length
  meta_description_length = metaDesc.length  
  word_count            = count words in content textarea
  keyword_in_title      = postTitle.toLowerCase()
                          .includes(focusKeyword.toLowerCase())
  keyword_in_meta       = metaDesc.toLowerCase()
                          .includes(focusKeyword.toLowerCase())
  keyword_in_first_100_words = first 100 words of content
                               .includes(keyword)
  keyword_density       = (keyword occurrences / total words) * 100
  h1_count              = count <h1> or # markdown headings
  h2_count              = count <h2> or ## markdown headings  
  image_count           = count ![  or <img in content
  images_without_alt    = images with empty alt=""
  internal_link_count   = count [text](/ links
  url_length            = urlSlug.length
  keyword_in_url        = urlSlug.includes(keyword)
  url_has_underscores   = urlSlug.includes('_')
  has_schema            = always false (can't detect from paste)
  flesch_score          = calculate using readabilityScorer.ts
  passive_voice_percentage = calculate from content
  avg_sentence_length   = calculate from content
  focus_keyword         = focusKeyword (empty = show missing rule)

Evaluate ALL 48 rules. For each rule that fires 
(condition is true / problem detected), add it to results.

OUTPUT PANEL (shown after analysis):

A. SCORE SUMMARY (top)
   Overall SEO Score: calculated as:
   - Start at 100
   - Deduct per fired rule: critical=-15, error=-10, 
     warning=-5, info=-2
   - Floor at 0, cap at 100
   Display as: large score ring (SVG) + score number
   + grade label: 90-100=Excellent, 70-89=Good, 
     50-69=Needs Work, 0-49=Poor

B. STATS ROW
   4 pills showing counts:
   🔴 X Critical  🟠 X Errors  🟡 X Warnings  🔵 X Info

C. ISSUES LIST
   Sorted by severity (critical first)
   For each fired rule show an expandable card:
   
   COLLAPSED STATE:
   [Severity Badge] [Rule message with variables filled in]
   [Impact Badge] [Effort Badge] [Time to fix]
   
   EXPANDED STATE (click to expand):
   - Explanation paragraph
   - "How to Fix" numbered list (from fix_steps array)
   - Example Bad (red tinted box if present)
   - Example Good (green tinted box if present)
   
   Rules that PASS (condition not fired) show in a 
   collapsed "✅ Passing Checks ({count})" section at 
   the bottom — green, collapsed by default

D. CONVERSION NUDGE (after results)
   Indigo box: "These {X} issues can be fixed 
   automatically with SEO Copilot plugin. 
   It checks every post on publish."
   Button: "Get the Plugin →"
